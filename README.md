# Typing Speed Test

A responsive typing speed test built with HTML, CSS, and JavaScript.

## Features

- Difficulty selection: Easy, Medium, Hard
- Passage language selection: English and Ukrainian
- Two modes: Timed 60s and Passage
- Live WPM, accuracy, and timer stats
- Character-level feedback for correct and incorrect input
- Restart with a random passage
- Final results screen
- Personal best saved in localStorage
- Responsive desktop and mobile layout

## Run Locally

Run a local static server:

```bash
python -m http.server 5173
```

Then open:

```text
http://127.0.0.1:5173/index.html
```
